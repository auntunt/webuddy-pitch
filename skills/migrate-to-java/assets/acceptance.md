## 状态定义

| 状态 | 含义 |
| --- | --- |
| `pass` | 在注明版本和环境中实际执行，结果满足注明的判定条件 |
| `fail` | 已执行，结果不满足判定条件；附差异与影响 |
| `blocked` | 缺少环境、依赖、信息或决定，无法完成该项验证 |
| `not-run` | 该项尚未执行；写明原因与计划 |
| `not-applicable` | 不适用于本次范围；写明依据 |

编译通过只支持构建结论；供应商兼容说明只支持其注明的范围；均不替代项目实际运行验证。
