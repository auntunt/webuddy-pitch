# 全项目分析：建立项目知识库

目标：像一位资深工程师接手项目那样，把整个系统理解一遍，并把理解**沉淀成可复用、可增量更新的知识库**。以后每个任务都从知识库出发，不再通读代码。**本技能不改业务代码。**

知识库在 `.tmh/knowledge/`，和代码一起提交：

| 层 | 页面 | 内容 |
|---|---|---|
| 总览 | `index.md` | 系统是什么、角色、业务域地图、技术架构、维护须知 |
| 业务域 | `domains/<id>.md` | 职责边界、核心流程、核心对象、与其他域的关系 |
| 业务流 | `flows/<id>.md` | 一个入口（接口/定时任务/消息）背后的完整业务 |
| 业务对象 | `entities/<表>.md` | 表的业务含义、关键字段、生命周期、谁在读写 |
| 代码模块 | `modules/<名>.md` | 职责、依赖、代码健康、维护建议 |
| 公共 | `glossary.md` `decisions.md` `pitfalls.md` `open-questions.md` | 术语对照、决定、坑、待确认问题 |

每页上半部分是工具从知识图谱生成的**事实**（带 文件:行号，自动更新），下半部分是你写的**理解**。

## 步骤

1. **构建图谱与骨架**：`tmh kb build`。看输出：节点数、业务域数、需要撰写的页面数。
   - 打开 `.tmh/knowledge/domains.json` 看自动划分的业务域。明显不对时（例如两个无关业务被合在一起）调整 `assign`，再 `tmh kb build`。域名称在写域页面时填 title 即可。
   - 用 `tmh note finding "<一句话>"` 记下第一印象（规模、核心表、技术栈）。
2. **逐页撰写**（循环，直到没有任务）：
   1. `tmh kb next` 领取一个任务。输出里有页面路径、写作要求和**上下文包**（事实 + 相关源码 + 下层页面的摘要，已控制在预算内）。
   2. 按要求编辑该页面：只写 tmh:facts 标记**下面**的部分，文件头填 `title`（中文业务名）和 `summary`（一句话）。
   3. `tmh kb done <页面id>`。校验不过就按提示改，直到通过。
   4. 新术语补进 `glossary.md`，【待确认】问题汇总进 `open-questions.md`，坑写进 `pitfalls.md`。
   顺序由工具保证：业务流 → 业务对象 → 模块 → 业务域 → 总览，上层页面用下层页面的摘要写成，所以上层不需要再读代码。
3. **并行**（任务多时）：把任务分给 `kb-writer` 子代理，每个子代理用不同的 `--who`（如 `--who w1`）执行 `tmh kb next --who w1` → 写页 → `tmh kb done <id> --who w1`，各自领各自的，不会冲突。主会话只看 `tmh kb status`，并负责业务域和总览页（需要全局判断）。子代理用便宜快速的模型即可。
4. **自检**：抽查 3 个已写页面，按里面的 文件:行号 回到代码核对；写错的改掉再 `tmh kb done`。
5. **出报告**：`tmh report`，生成 `.tmh/report/`（index.html + data/，整个文件夹离线打开）。按 业务全景 → 业务域 → 业务流 → 代码 下钻；“项目构建”页签是技术栈、分层、部署和风险。你写的页面显示在“业务理解”栏，带 `文件:行号` 的句子标为“代码核实”，【推断】标为“模型推断”。
6. **汇报**：系统是什么；分成哪几个业务域；写了多少页（`tmh kb status`）；最大的风险和未知；需要业务方确认的问题（open-questions.md）；报告位置。

## 原则
- **只用上下文包**。确实不够才打开具体文件，不要按目录通读。上下文包已经包含了这一页需要的源码。
- **事实与推断分开**：读代码得到的写证据 `文件:行号`；推断标【推断】；需要业务方回答的标【待确认】。注释里说了但代码没实现的，要指出来。
- **不要自己把页面标成“已确认”**：那是人看过之后用 `tmh kb confirm <id> --by <姓名>` 做的。
- **宁短勿错**：一页一屏以内，结论比复述代码重要。
- 规模很大的项目，工具默认每个业务域只纳入最重要的 25 条业务流（写表、改状态、有规则的优先），只读查询类入口只保留事实。需要时用 `tmh kb next --page flow:<id>` 单独补写；也可在 `.tmh/config.json` 里设置 `"kb": {"max_flows_per_domain": 50}` 或 `"all_flows": true`。
