## 命令动作的原样留痕

`capture_step.py` 用独立目录保存实际命令、工作目录、开始/结束时间、退出码及完整stdout/stderr字节和摘要，不覆盖旧步骤。actor是填写的标识，不是身份认证；exit 0只证明命令退出成功，不证明业务验收。

```sh
python3 examples/project-testing/jsherp/jenkins-demo/capture_step.py \
  --output "<演示根目录>/proof/steps" --label "核对环境" \
  --actor "实际操作者" --actor-type human -- \
  python3 examples/project-testing/jsherp/jenkins-demo/manage.py status
```

命令参数及输出中不得带凭据。需要凭据的操作引用已有安全文件/环境变量；捕获前确认程序不会回显凭据。不记录全部环境变量、不录入密码、不上传private目录。Agent执行必须使用actor-type agent；真人尚未执行的步骤不得用脚本代跑后写成人工完成。

本工具不是防篡改审计服务；摘要用于发现后续内容变化，可信身份仍来自现有账号审计与真人签名。超时只能保证直接子进程被终止，不能替代平台现有进程树清理。需交互/长期服务的步骤使用现有执行器回执，不能用此工具绕过生命周期管理。
