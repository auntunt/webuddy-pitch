# 怀柔局域网内测版

独立实例设置 `WEBUDDY_LAN_SIGNUP=admin` 后，浏览器可在 `/login` 注册个人账号。注册成功直接进入工作台，登录状态保留七天。注册账号具有管理员权限；默认部署不开放注册。账号重名不会覆盖已有密码，注册请求必须来自本站。

Windows 怀柔实例沿用独立数据目录和 8791 端口。网页首页在没有项目时展示接入项目和执行器设置入口；已有项目继续使用任务队列与完整功能目录。

Java 图谱保留方法分组，同时新增每个声明的独立节点，记录包名、文件、完整参数声明和来源版本。修复 Java 数组参数被当作 C# 属性删除的问题；嵌套类包含外层类名。同名类不再合并方法节点，重载不再任意选第一个方法体推断调用；不能唯一解析的调用显示不确定。

当前仍是结构静态分析，不是 Java 编译器：重载参数类型、复杂泛型、反射和运行时依赖注入尚未完整解析。多来源图谱联邦仍按原设计逐步实现；本次不宣称复杂真实 Java 项目的全部调用边已正确解析。
