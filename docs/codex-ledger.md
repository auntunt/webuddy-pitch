# Codex 独立持久台账：无模型批

本批只提供单一选定 SQLite 数据库内的有限记账，不启动 CLI、任务或模型，不发布技术合格报告，不接人工采用。导入模块没有建表副作用；显式构造 `scripts.rsi.codex_ledger.Ledger(path)` 才初始化三个 `codex_learning_` 表。不修改旧 `rsi_prepare_`、native/provider/BC 链。

合同沿用严格的 `codex-learning-finite-v1` 格式。`register` 另固定微秒单位的绝对开始、结束点，窗口不得超过合同总时限。同 root 的合同、窗口和初始代际只能幂等读取，不能替换或刷新。当前仅在临时数据库验证合成合同，没有登记真实任务或新试点。

所有写操作用 `BEGIN IMMEDIATE` 串行化，检查 FULL/EXTRA 同步及有日志模式。预留、输入摘要和事件同事务提交；`intent` 状态、唯一 token 和事件同事务提交。事件写失败整笔回滚，禁止隐式提交调用者事务。两个真实连接使用相同 request 只得到一个新 intent；不同 request 也不能绕过串行在途限制。

预留永久占用原累计槽。`reserved_total` 包含已取消、已结算和执行未知的历史预留；`intent_total` 统计曾登记 intent 的记录，不因状态变化减少。这两个数字都不是实际 CLI 启动数或 HTTP 次数。

| 状态 | 含义 |
|---|---|
| reserved | 输入摘要已固定并占槽，尚无 intent |
| intent | 已持久登记意图，不能证明进程已启动或未启动 |
| settled | 已录入固定摘要与完成/失败声明，尚无可信生产者认证 |
| unknown | intent 后结果无法核对，停止本 root 后续操作 |
| cancelled | intent 前停止，槽位仍占用 |

`settle` 的完成声明不是执行成功或任务验收；当前没有真实生产者适配。所有实际启动数、任务验收和计量/实付均保持未知，采用、准入与生产者认证标志保持 false。计量未知不自动变成执行未知，也不补零。录入完成声明后可以测试下一次预留，但不能据此派发真实工作；失败声明会保守停止本 root。

取消、到期、时钟回退、代际丢失和执行未知均为持久停止。intent 前转 cancelled，intent 后转 unknown。操作因停止而抛出 `Stopped` 时，停止事件仍已提交；其他异常回滚，调用者不得把异常当作成功持久化。停止后不能用换 request、重开连接、重放结算或注册原合同复活，也不返还槽位。

时间判断使用墙钟和本实例的单调时间推进，结束点始终来自原登记；重开不延长登记窗口。墙钟较上次提交值回退，或本实例单调时间回退时停止。generation 是调用者所有权标签，默认在进程内共享、fork/新进程变化，不是操作系统身份认证。新代际调用写接口或 `reconcile` 会锁存停止。`snapshot` 只读历史快照，不刷新时间、恢复任务或授权派发；需要锁存生命周期变化时显式调用 `reconcile`。

约束只在该选定数据库内成立。跨数据库复制、备份回退、root 别名及直接篡改数据库，不在本批全局防重或来源真实性保证内。这里只补 C03–C05 的单库事务与累计部分；输入保存的是调用者提交的摘要，不是已核对的真实资料、当前权限或来源承诺。可信派发、真实进程/输入送达证明、原件认证、留出隔离和真实任务验收均未准入；不能将此台账与文件绑定核验简单拼接成可采用凭证。

验证命令：`python3 -m unittest -v tests.test_codex_ledger`。只使用临时 SQLite、两个真实连接、真实触发器故障注入和一个本地 Python 重开进程，不访问凭据、私有留出、生产数据库、模型或网络。
