# 真实事项编辑、验证与固定版本预览

日期：2026-10-18。分支 `codex/self-evolution-resume`，基线 `79e86db`。继续使用本地 `data/product-workbench`，没有操作生产、合入主干或推送远端。

## 任务与结果口径

本轮选 BOOTV2 的一条完整技术路径：用户可以编辑已有事项标题，保存后刷新或重启仍保留原 id 和完成状态；无效输入与存储故障可恢复并重试；工作台展示实际改动和验证结果，采纳到独立分支后打开对应提交的应用。完整原始请求在 `evidence/2026-10-18-implementation/request.json`。

这是轻量应用的一条真实路径，不代表客户任意需求已完成，也不代表已经自动化软件开发的所有阶段。技术采纳使用 `自动流转` 身份；没有替用户作需求、设计或客户签收。已有全周期工作台继续保留原阶段状态。

## 本轮产品改动

- 新项目模板支持编辑、保存、取消，采用真实 HTTP 与 SQLite，标题只更新原事项。转义显示输入，错误页保留可恢复的原文、目标 id 和重试入口。
- 合法标题为 1–200 字；保存请求上限 8192 字节。编辑请求可在 64 KiB 的有限窗口内完整回显错误输入；超过窗口在读取正文前拒收并关闭连接，明确说明未接收、未保存，绝不静默截断。普通页面使用原生 `maxlength`，不为此增加脚本依赖。这个明确的传输边界不等于原始机器生成合同中“任何超长输入均恢复”的无条件说法。
- 运行详情增加真实验证、独立分支采纳、当前运行预览和失败恢复入口。异步状态绑定当前运行与最新请求，避免旧请求覆盖刚启动的新预览。
- 预览 URL 包含完整提交号；访问授权、转发与停止都检查当前版本。旧页面在换版后返回 409，不会把旧页面表单提交到新版本。主干预览与运行预览分别标识。
- 重检保存历史验证和差异；实现改变使旧模型诊断失效，真实构建结果与模型判断分别显示。已采纳提交的临时测试目录即使被测试修改，也不能污染原提交的展示差异。
- 采纳前检查运行正常结束、真实命令结果、诊断失败、越界文件以及验证记录可读性，并核对实际代码与展示/验证版本；暂存后再核对，阻止验证后改码仍用旧结果提交。
- 完整当前要求传给初次执行、续聊与重试；未安装分析工具的项目不再得到虚构的工具命令。历史原文和模型输出仍完整保留。

## 失败与独立介入

真实 Codex 使用已有默认模型配置完成规划，随后进入修改和诊断。模型沙箱无法绑定本地端口；模型自行报告的内存传输测试与外层实际 TCP 测试分开记录。

初版超过 8192 字节错误输入不能恢复；第二版为此无上限接收正文并使用临时文件，独立复核拦下资源风险。后续模型改为有界恢复和脚本路径，但诊断仍纠结无上限恢复。独立代理在保留原行为测试的基础上形成较小的标准表单候选，明确有限接收窗口。最终采用候选与原始模型输出分别归档，不能把独立介入后的结果算作模型独立一次修对。

复核还发现百分号编码的非法 UTF-8 可被 `parse_qs` 默认替换为 `�` 后保存；最终候选改为严格解码，错误请求返回 400，数据库不变。旧候选及其验证记录保留，修正版本使用 `independent_bounded_v2_*` 文件名。

平台侧真实 Git 复现出“验证后改码仍能采纳”和“损坏验证 JSON 被视为无记录”两项缺口，已加入拒绝路径及回归。最终证据清单记录后续复核结果。

进一步复现了 HEAD 已变而未提交 diff 相同的情况；仅比较 diff 不能证明同一基线。重检新增完整 `checked_base`，采纳在暂存前后均核对 HEAD。重新验证新基线后才可采纳，旧基线保留于历史。此修正有真实 Git 回归和第二人独立复核。

最后一次修改调用的 Node 包装进程结束后，原生 Codex 进程仍以 PID 1 为父进程继续运行。主代理按精确工作树及 `last-message-7.md` 定位并终止其遗留进程树，让外层验证继续。没有终止其他项目、8792 或用户其他任务。原进程列表和停止原因见 `stalled-call-stop.json`；长墙钟时长可能含主机休眠，不应直接当作模型计算成本。

## 浏览器验收

在隔离候选服务实际新增事项、完成、编辑为空白、改正含脚本样式的普通文字、刷新、取消；随后将隔离 SQLite 文件可逆改名并用空目录模拟不可用，保存出现 503 且保留输入，恢复原文件后重试只更新 id=1，done=1，记录数仍为 1。没有操作客户数据。

320 与 375 像素视口的 `scrollWidth` 均等于视口宽度；320 像素按钮实际高 46.5 像素。视口随后恢复。截图保存浏览器原始字节和完整像素，没有压缩或转码；桌面和窄屏是独立采集。详见 `browser-candidate-observations.json`。
