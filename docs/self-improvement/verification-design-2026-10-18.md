# 全站页面改版验证 · 2026-10-18

基线 `07cdb21`，分支 `codex/self-evolution-resume`。依据用户指定的 Impeccable 与 Design Visual Frontend 改造现有 Python 单页工作台，不更换技术栈、不引入外部字体或 CDN。

固定参考版本、具体设计决策与适用边界见 [设计依据](../design/redesign-2026-10-18.md)。产品与视觉约定写入根目录 `PRODUCT.md` / `DESIGN.md`，供后续自进化延续。本记录为本地技术验收，不是客户签收或生产发布。

## 实现

- `ui_theme.py`：浅色工作面与森林绿强调色，统一全站导航、表单、按钮、表格、工程面板、弹窗、助手、文字状态和焦点；手机底部导航，平板明确两行顶栏，宽屏限制内容宽度。
- `ui_delivery.py`：真实关键词/状态筛选、阶段产物复核数量、阶段侧轨、移动端展开阶段、状态驱动下一步；新建、草稿恢复、全文编辑、采集、运行和版本复核入口保持可用。
- `ui_work.py`：六项 SVG 主导航及当前页标记；今日、客户、需求、版本和工单摘要统一。原文完整换行；版本展示实际预览状态，分享不再表述为验收。定时更新不再无条件重建导航并夺走键盘焦点。
- `ui.py`：点数和用户入口改为原生按钮；弹窗具备名称、焦点进入/循环/恢复和背景隔离。助手覆盖弹窗时只把可见助手纳入键盘范围，Escape 先关助手并保留弹窗。
- 浏览器验收额外发现运行列表隐藏无会话的阶段 `ask` 任务；现已显示。原模型输出改为完整可展开的历史记录，提醒查看当前代码与实际验证，避免旧结论被误读为当前成功。

## 边界与接续

改版改进了实际工作台的布局与可操作性，没有补造全周期能力，也没有改变质量、安全、合并和签收门槛。客户页当前只有空态与表单数据，尚未在本轮创建真实业务客户；大量历史数据与多用户并发仍属 SI-006 后续范围。

下一轮仍优先 SI-007（质量/安全固定受检版本）和 SI-008（运行总时限/子进程），并以本轮设计规范保持统一。记录一个界面细节供后续处理：运行弹窗的助手“当前页面”可能取到历史 Markdown 的第一个 h2，应该用明确的运行标题；它没有影响本轮实际运行记录与验证结果。
