## 失败与复验

- 来源旧行为反例先失败，`provenance-before.log` 保留；修复后正确绑定 A/快照。
- 初次导出读取因 Store 将名为 data 的字段当 JSON 解析而失败，改用 segment；冷导入测试最初错误地要求启动期也无包缓存，按真实审计边界纠正，未关闭只读保护。
- 一次测试命令引用不存在的测试文件，未运行；`a-regression-final.log` 保留，正确文件复跑另存。
- 浏览器脚本最初引用了仅在 Node 存在的变量，修复脚本后继续。
- 亲看截图发现网页下载误将 JSON 字段顺序差异当内容变化；改为稳定字段比较。之后脚本要求实际文件落盘，`a-browser-download-fixed.log` 与 `browser-downloaded-plan.json` 为复验。早期“按钮恢复”的日志不能作为下载成功证据。
