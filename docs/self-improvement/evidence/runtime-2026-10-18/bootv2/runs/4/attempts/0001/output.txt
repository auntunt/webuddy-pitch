统一编辑错误处理契约：

- 请求体解析及大小限制沿用现有行为；无效CSRF返回403，不访问数据库。
- 非法编辑路径或非法 id 返回404。
- 对合法编辑路径，先记录待保存上下文，再连接数据库、确认目标存在；不存在返回404。
- 目标存在但标题不合法，返回400，保留原输入并提供修正后重试及返回入口。
- 数据库连接、查询、更新或提交异常，返回503，保留目标及输入。
- 编辑403/404页在已收到输入时也应安全回显并提供返回入口；任何错误均不得转为新增。
- 同时发生数据库不可用和标题非法时，按上述顺序返回503。保留现有8192字节请求体上限，超限仍返回413。

    def call_response(self, method, path, data=None):
        body = urlencode(data).encode("ascii") if data is not None else None
        return self.call_raw_response(method, path, body)

    def call_raw_response(self, method, path, body):
        conn = http.client.HTTPConnection("127.0.0.1", self.server.server_address[1], timeout=5)
        try:
            conn.request(method, path, body,
                         {"Content-Type": "application/x-www-form-urlencoded"})

            headers = dict(r.getheaders())
            response = r.read()
            self.assertEqual(int(headers["Content-Length"]), len(response))
            return r.status, headers, response.decode("utf-8")
        finally:
            conn.close()
