# 怀柔版：Java 知识试用与成果阅读

本次更新统一主要按钮、知识页导航和成果排版。分析、方案、验证报告支持标题、表格、列表、引用和代码；窄屏表格按行阅读。知识原文完整保留，可展开查看。知识目录独立滚动，构建页显示本轮页数、进度和记录，默认每轮 3 页。

新接入项目启动知识构建时自动准备工具运行时和 Cursor 知识桥，不再要求手动安装项目工具；保留项目已有指令。分析输出先给结论与下一步，并区分架构盘点、不兼容证据、改造方案、实际改动与验证结果。
