# Webuddy

Webuddy 为软件维护提供项目知识、需求与改造计划、受控运行、候选及验证证据。网页、CLI 与 MCP 通过同一服务和权限管理任务。

- [安装、配置与升级](installation.md)
- [静态知识构建与读取](knowledge.md)
- [验证与人工验收](acceptance.md)
- [运行边界](operating-boundaries.md)
- [Agent 命令](../agent-commands.md)

本发行包包含产品 Python 源码；不提供源码混淆、编译保护或许可证系统。第三方组件遵守各自许可证。

离线运行环境可以在不下载依赖的情况下启动网页和静态工具。模型服务仍需获准账号或可达的内网服务；包内没有模型权重、账号、业务数据或预建项目知识。
