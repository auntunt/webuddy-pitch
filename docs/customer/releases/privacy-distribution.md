# 发行内容边界

客户包包含产品运行代码、锁定运行环境、通用模板、技能、Agent指引和第三方许可。产品源码示例使用通用账号、保留示例域名及示例地址；容器内固定的 `/home/worker` 为程序接口约定，不是个人主目录。

真实连接地址、端口、身份和凭据由包外配置提供。SSH及Windows PowerShell传输能力保持，不预置内部连接资料。

内部研发、部署和验证原始记录保留在本地私有目录，退出公开版本控制。不要上传该目录、个人配置、业务数据库或项目知识。公开交付摘要不得包含内部地址、本机路径、账号或运维原始日志。

普通提交只改变当前版本。已发布Git历史及旧发行物需要单独清理，不能将当前文件已剥离表述为历史已删除。源码提交作者元数据也不是运行配置。
