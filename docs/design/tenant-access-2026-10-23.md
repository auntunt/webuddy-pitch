# 租户与权限实施合同

起点 `ace189d`。用户授权实现、验证、推送并发布。本文记录实施判断，不代表已验收。

## 隔离结构

统一入口使用 `/t/<不可变租户ID>/` 固定选择租户。租户配置由控制面保存，客户端不能传 data/workspace 路径、后端端口或主机。未知/停用租户失败关闭。各租户独立 SQLite、文件目录和服务进程；不修改共享 Platform 的“当前租户”。旧数据原位登记 default，保留旧 ID、作者、证据及项目路径。

控制面账号与成员授权使用独立 SQLite，管理决定、审计及请求回执同事务。已有用户只迁为普通成员；平台管理员显式指定。平台管理员管理租户和账号；租户管理员管理本租户成员与项目授权；普通成员按项目 manager/contributor/viewer 授权，租户 viewer 不能写。项目角色不替代指定复核人、来源绑定或业务验收。

请求身份由统一入口的真实个人会话产生（本轮未提供服务凭据，不接受旧共享令牌代替个人身份），worker 不信用户自报的身份/权限头。页面固定授权上下文；切租户整页重新加载，不把旧页面表单提交到新租户。撤权、账号禁用和密码变化使旧上下文失效。授权变更与已接纳业务操作串行登记，重试仍先验证当前授权。

网关先校验并签署固定的身份、租户、方法、路径、正文摘要和授权上下文；私有 worker 在执行时重新验证，并持有跨进程授权锁直到业务处理结束。授权锁不能只由网关持有，否则网关死亡会让仍在提交的 worker 失去撤权屏障。两端均在释放授权锁后发送响应，慢客户端不会阻塞全局撤权。worker 启动和就绪等待在授权锁外完成，锁内不重启死亡 worker。

## 数据及执行边界

所有 API 与 `/e`、`/p`、分享/签收/预览/回调入口都先固定租户。资源 ID 在本租户数据库反查项目，再校验访问级别；跨项目字段和来源同样检查。列表、计数、搜索、分页先过滤。未实现安全过滤的全局聚合仅租户管理员可用。未知接口默认拒绝。

项目根、知识来源、派生目录必须在服务器批准的租户目录内，拒绝越界、符号链接和另一租户目录。浏览器不直接提供宿主命令或路径权限。跨租户知识分享不复用同库 grants；未有显式跨租户发布协议时拒绝。

服务进程分开不等于执行代码的 OS 沙箱。新租户默认关闭代码、构建、模型工具执行、预览与自动恢复，本轮没有启用开关，需后续实现并验收独立受控执行环境后才能开放。现有默认租户的原宿主执行仅允许可信平台管理员；普通租户管理员不能自行打开执行或修改测试机/模型凭据。管理页面明确显示执行状态和禁用原因。

公开能力链接和预览服务在全部受管租户保持关闭，不能把默认组织所有者的宿主执行权当成同源预览许可。普通成员的 Git 证据核对也被执行后备门拒绝，依赖它的评审尚不可用；本版没有为了恢复该能力放行通用 Git 命令。支持边界和操作流程见 [使用说明](../tenant-access.md)。

## 验证与发布

控制面迁移/回滚、最后管理员、CAS、同请求重放、撤权与写入竞争；两个独立 worker 的同名项目/工单/运行/请求编号碰撞；直接 API、非 API 下载、Agent 通道、公开能力票据、路径越界；禁止执行时零子进程/零执行队列；跨标签页/迟到响应/草稿/窄屏检查。

原断言与业务状态机保持。精确实现冻结后跑全量；真实数据只用完整一致性副本迁移演练。发布前保留完整程序、配置和业务数据备份，回退不覆盖上线后的新数据。最终状态及命令结果记录到 Ralph 进度文件。
