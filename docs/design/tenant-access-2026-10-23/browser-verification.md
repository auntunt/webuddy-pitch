# 租户与权限 UI 浏览器验证

日期：2026-10-23。对象：本地未提交的租户隔离与权限 UI 实现；最终 UI 源码冻结后重启夹具并保存最终管理、只读及撤权截图。仅使用仓库外合成数据、独立回环端口，不连接生产，不做业务验收、关单、模型执行或真实权限调整。

## 环境

仅在独立的本地临时平台与合成数据中验收；两个租户使用相同项目编号和 ID、不同标题和材料，验证路径、缓存和草稿隔离。完整夹具与操作记录保留在仓库外。本目录不包含数据库、账号凭据或夹具脚本。

## 实际浏览器检查

| 场景 | 结果 |
|---|---|
| 平台管理员 登录并选择租户甲 | 展示有效租户和当前身份 |
| 在管理页添加 新增成员 成员 | GET 目录展示新增成员，权限版本递增 |
| 将 新增成员 授权为项目只读成员 | 目录展示项目 ID 1 的 只读成员 授权 |
| 填写创建租户表单后刷新目录 | 名称与管理员草稿保留；提交后出现新租户“浏览器验证租户丙”，管理员 另一管理员 |
| 管理变更后继续旧 context 请求 | 409 后旧业务 DOM 被清除，明确要求重新读取；重新读取展示已提交变更 |
| 平台管理员 没有乙租户业务成员身份时直接访问管理页 | 展示控制面与无业务成员提示，不加载业务项目工作区 |
| 协作者 在甲租户写入交接草稿后切换到乙 | 乙的同编号任务展示不同正文，交接草稿为空 |
| 协作者 从乙切回甲 | 交接说明“甲租户独有草稿：不可出现在乙租户”和完整材料“完整材料甲：字段 A 与验收步骤 B”原样恢复 |
| 协作者 手工新建任务 | 保存为 SAME-2，真实详情显示“自动处理已关闭”、0 次运行；分析定位入口禁用 |
| 只读成员 390px 宽屏幕 | 只读说明和禁用原因可见，新建任务/记录需求/执行入口禁用；责任人完整显示 |
| 390px 管理页面 | 全部管理字段、成员和授权记录可读，document scrollWidth=clientWidth=390，无横向溢出 |
| 管理员在第二会话撤销 只读成员 项目授权 | 只读成员 原页面刷新后整体清屏，不残留旧任务；重新读取后 0 项目/任务，不出现 SAME 数据 |
| 最终浏览器控制台 | 错误记录为空 |

## 定向自动化证据

- 新增 `tests/test_ui_access.py`：最终 37 项通过。最后两项验证知识答复使用真实会话账号、拒绝可编辑姓名输入并完整提交原文，先红后绿。
- UI 定向集合：154 项通过；随后仅补充权限文案、assign/claim 限制及只读新建任务禁用，已对 35 项新增回归重跑通过。最终全量由根代理在冻结后执行。
- 确定性 JS 回归涵盖 context 与迟到响应隔离、同一 request_id/完整 payload 的未知结果重试、无效回执、刷新保留草稿、失效接收人/项目、密码不落存储、控制面专用启动、项目角色及执行限制。
- 未在浏览器中故意制造断网或 5xx；上述未知结果重试以自动化 JS 回归为证据，不声称真人浏览器执行了该故障场景。
