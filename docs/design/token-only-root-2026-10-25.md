# 100M Token授权与显式Token根合同

本增量起点b61771f，只修改离线准备Ledger及其测试/说明。真实人类2026-10-25答复明确100,000,000 Token替代旧20元费用上限，PPT自动化预定19:30至次日00:30试运行；这不是实际启动回执或长期双周期试点。旧v1/v2/v3金额合同及历史不转换、不重写，新授权不因价格未知而停止，但调用仍须满足可信Token单次上界。

新增`trial-token-proposal-v4`及供后续明确Adapter接线的`trial-token-provider-v5`。原四表DDL保持；字段仍受精确校验。新合同没有price及cost_micro_cny额度，不能填零价或MAX伪装金额许可。`budget.unit=tokens`，绑定原人类授权摘要、原先已知Token、原先未知最大占用及其证据摘要；`limits`含调用数、总Token、固定starts_us/deadline_us，重试不重置日历。

同一权威数据库中，一份授权摘要只能属于一个原根，换根名、租户、项目或模型不能再取得同一份额度。事务内检查原create锚及全部既有根，两个连接竞争不同根也至多一者成功；根行丢失而历史仍在时拒绝重建。此内部合同依赖可信调用者提供真实授权/既往调用范围；摘要本身不是授权证明。生产接线必须指定唯一服务端根和权威账本，不允许客户端选择另一个数据库、制造新授权摘要或每个端/模型另起100M根。当前仍冻结单模型，不声称多模型派发已经实现。

所有阶段propose/baseline/candidate/judge/probe/retry/terminal/followup继续用原预留、唯一intent、原期限及总计量。完整输入Token含缓存读写，输出包含在提供商父项内的推理Token，不按价格折算。已结算用确认Token；未发出意图的取消只释放Token占用、不释放尝试次数；意图后取消、未知、未决隔离保留原最大输入+输出预留并封根。原先未知占用存在时也拒绝新派发；晚到结算仍不恢复派发。此前生成候选的一次绑定与预封B/C消费保持同事务，不刷新原合同。

未知金额在预留、汇总和展示中为null；实际回执提供的金额仍原样保存在原事件，不成为本轮权限门。`inspect.token_budget`列出confirmed_used、reserved_or_unknown、remaining、固定窗口、阻断原因与每个request/phase来源。实际金额缺乏独立验证时仍unknown，不从Token推导人民币收益。

既往调用须先明确归属：本轮授权窗口以外、其他合成/配置canary保留原历史，不能冒称本试轮工作；窗口内任何已发生调用必须按已知或最大未知Token写入新合同初始占用。不能为取得新额度遗漏历史，实际开始时间不能回填预定时刻。

本批不增加生产路由、个人工具执行权、模型请求或Store自动迁移。原Adapter仍拒绝v4/v5；接下来的窄增量须实现明确协议/可信硬上界、原始响应派生、共同renderer及原根桥。账本只能在请求前预留，无法撤销提供商已经发生的超额；手填input_cap或事后usage不足以证明真实硬限。可信硬上界未闭合时，真实调用继续拒绝，与旧人民币价格门无关。

验证覆盖旧金额合同、新合同显式字段/金额null、100M恰好耗尽、超额在intent前拒绝、缓存输入包含口径、全阶段累计、未知/晚结算、取消、固定窗口/代际、既往占用、同授权换根拒绝及真实双连接并发。执行结果、原失败、稳定性和负控见进度文件；旧全量不挪作本增量结果。guard/acceptance/锁、人工采用/验收/关单、原断言和超时不改。
