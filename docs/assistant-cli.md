# 小助手使用已有 AI 执行器

侧边小助手和新版 AI 助手都能按项目路由使用已配置的 Cursor CLI、Codex 或 Claude，不再要求额外配置直连模型 API。已有 API 助手继续保留原有工具操作与权限检查；明确配置 CLI 的项目通过现有运行队列回答。

CLI 问答结合当前项目、会话历史、工单和知识资料；侧边助手额外传递当前页面名称与路由，不读取页面中的密码等表单值。此路径用于回答、分析和整理草稿，保留“起草工单”入口，不声称已自动创建任务或修改代码。

对话保存运行编号，显示等待与回答，支持停止和断线后继续读取同一次运行。重复发送同一请求不会重复启动。项目执行器允许列表和租户执行隔离要求仍然生效。
