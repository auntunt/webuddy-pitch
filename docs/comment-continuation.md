# 评论续接任务

任务讨论区的“评论并继续”先保存评论，再通过现有执行入口启动后续运行。请求编号绑定评论与执行回执，网络重试不会重复启动。失败或取消的任务使用原恢复流程；其他任务沿用最近运行的模式和执行器，没有历史运行时先分析。

评论全文进入模型上下文；续接会话包含上轮开始后提交的评论，避免遗漏执行期间补充的信息。未提交的草稿不会发送。

已有任务运行时，评论会保存，页面提示结束后重试；不会并行修改同一工单。已完成开发的工作树存在未提交改动时会保留原成果并报告阻塞。既有执行、版本及验收约束继续适用。

本变更不提供自动 Git 初始化、环境安装或 Git 推送能力。评论不能改变执行器的权限或绕过发布限制。推送仍需独立执行流程支持。
